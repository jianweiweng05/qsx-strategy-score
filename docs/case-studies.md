# Reproducible screening examples (v0.4.0)

These are software demonstrations using the three existing bundled CSVs. They are not independently labelled strategies, live performance, or evidence of alpha. The filenames `strategy_alpha.csv` and `strategy_beta.csv` do not establish either property. No input, threshold, profile or seed was changed to obtain a more favorable result.

**中文：** 以下三个原有样例用于复现软件输出。前两个因缺少基准而为 PROVISIONAL；第三个有明显异常提示。文件名中的 alpha/beta 不代表已验证的策略性质；旧版 SILVER 和随机检验 p 值不适用于本表。

For all three, buy-and-hold comparison and random-control p-value are **N/A**, with `BENCHMARK_MISSING` and `EDGE_NOT_ESTABLISHED`. A high path score does not replace these checks. The old screenshots, SILVER label and p-values are not current-version evidence and are deliberately omitted.

`sample_flagged.csv` is a deliberately smooth synthetic example generated by [`make_samples.py`](../examples/make_samples.py). These checks identify patterns to investigate; they do not establish look-ahead bias, fraud or the cause of a suspicious result.

## Reproduce from the published core tag

Use Python 3.9–3.12 and Git. This installs the existing GitHub **v0.4.0** tag directly, without relying on a package-registry release. The three input files are unchanged between that tag and this documentation revision.

```bash
git clone --branch v0.4.0 --depth 1 https://github.com/jianweiweng05/qsx-strategy-score.git
cd qsx-strategy-score
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
qsx-score --version
mkdir -p reports/case-studies-v040

qsx-score examples/strategy_alpha.csv --profile other --no-auto-asset --lang en --json reports/case-studies-v040/strategy_alpha.json
qsx-score examples/strategy_beta.csv --profile other --no-auto-asset --lang en --json reports/case-studies-v040/strategy_beta.json
qsx-score examples/sample_flagged.csv --profile other --no-auto-asset --lang en --json reports/case-studies-v040/sample_flagged.json
```

On Windows, use `.venv\Scripts\activate` to activate the environment. Each command prints its report and saves JSON. Inspect `display`, `grade`, `tier`, `flags`, `evidence` and `meta.random_p` together. JSON also records normalized input/benchmark hashes and comparison limits. Reports are ignored by Git.

The table was reproduced with Python 3.9.6 in two environments: NumPy 1.24.4 / pandas 2.0.3, and a fresh installation with pip 26.0.1 / NumPy 2.0.2 / pandas 2.3.3. The fresh environment produced identical full JSON on two runs of each example. Dependencies are not pinned by the package; record your versions if investigating a difference. Core version is `0.4.0`, scoring rule `daily_proxy_v4_2026-10-04`, profile `other`, default RNG seed `12345`. Search-trial count is omitted, therefore **unknown**, and DSR is N/A. Calibration remains `VALIDATED=False`.

## Optional benchmark comparison

A fresh clone does **not** contain downloaded asset prices. To run a BTC comparison, first obtain the data, then explicitly select it:

```bash
python -m qsx_strategy_score.assets --keys BTC
qsx-score examples/strategy_alpha.csv --profile other --asset BTC --lang en --json reports/case-studies-v040/strategy_alpha_with_btc.json
```

The download needs network access to the public source. Alternatively, supply actual overlapping `date,close` benchmark prices:

```bash
qsx-score examples/strategy_alpha.csv --profile other --no-auto-asset --benchmark your_prices.csv --lang en --json reports/case-studies-v040/strategy_alpha_with_benchmark.json
```

This is a separate comparison, not a reproduction of the table or the old p-values. Record the source, data cutoff, price/total-return convention, currency and file hash; check overlap and the supported daily comparison contract. If a check is unavailable, retain its N/A reason. Do not try multiple assets or settings and present the most favorable result as independent evidence. An available daily signed-beta proxy still cannot certify actual timing skill or real exposure.

These examples do not measure external calibration accuracy. See the [input and comparison contract](input-comparison-contract.md), [calibration policy](calibration.md) and [scoring model](scoring.md). Missing evidence can be supplied and the free check rerun; no paid product is required to interpret PROVISIONAL or N/A.
